## ✨ Overview

Welcome to the source code of **Raghav Sharma's personal developer portfolio**.

This project is designed to be more than a traditional resume website. It combines a **dark premium interface, smooth navigation, interactive animations, animated backgrounds, glassmorphism elements and responsive layouts** to create an engaging digital identity.

The portfolio showcases my:

* 👨‍💻 Technical skills
* 🚀 Projects
* 💼 Experience
* 🏆 Achievements & certifications
* 📄 Resume
* 📬 Contact information
* 🌐 Developer and social profiles

The website is intentionally built with **vanilla HTML, CSS and JavaScript**, keeping the project lightweight, understandable and easy to customize.

Because this is primarily a static website, there is no complicated framework setup required.

### Option 1 — Open Directly

Simply open:

```text

```

in your browser.

---

### Option 2 — Python Local Server

If Python is installed:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

Using a local server is recommended when working with assets, animations or browser security restrictions.

Install the **Live Server** extension in VS Code.

Then:


# 🧩 Design Philosophy

The portfolio follows a few key principles:

### 01 — Minimal but Interactive

The interface avoids unnecessary visual clutter while using animations where they add value.

### 02 — Storytelling

The website communicates a developer journey instead of simply displaying a resume.

### 03 — Visual Hierarchy

Important information such as:

```text
Name
Role
Projects
Experience
Achievements
Contact
```

receives stronger visual emphasis.

### 04 — Responsive First

The design is intended to remain usable across:

```text
Desktop → Tablet → Mobile
```

### 05 — Lightweight Architecture

Instead of relying on a large frontend framework, the current implementation uses standard web technologies.
